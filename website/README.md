# gonsoft-labs.de

Quellstand der Firmen-Website von Gonsoft Labs. Die Seite liegt produktiv auf
dem STRATO-Webspace und wird **von Hand per WebFTP** hochgeladen – es gibt
keine automatische Auslieferung aus diesem Repository.

Abgelegt hier, damit der Stand nicht ausschliesslich auf dem Webspace existiert.

## Inhalt

| Datei | Zweck |
|---|---|
| `index.html` | Startseite (Leistungen, Produkt Rivello, Ueber uns, Kontakt) |
| `impressum.html` | Impressum |
| `datenschutz.html` | Datenschutzerklaerung |

## Nicht im Repository

Diese Dateien liegen nur auf dem Webspace bzw. auf dem Arbeitsrechner:

- `assets/styles.css`, `assets/main.js`
- `assets/logo.png`, `assets/darius.jpg`, `assets/og-image.png`
- `assets/fonts/sora-800.woff2`
- `assets/rivello-app.png`, `assets/rivello-phone.png` (Produkt-Screenshots, stehen noch aus)
- `assets/video/rivello-spot-1..4.mp4` (Werbespots, je ca. 16 MB; Quelle sind die
  Build-Skripte der Rivello-Kampagnen)

Die Videos sind bewusst ausgelassen: rund 63 MB Binaerdaten wuerden dauerhaft in
der Git-Historie liegen, obwohl sie reproduzierbar sind und auf dem PC vorliegen.
